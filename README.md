A [make.fun](https://make.fun/bounty/the-poem-about-stopping-20261121-1927) entry: a program that writes one short poem about agency — the power to stop and to stay.

## The poem

> The train went on without me.
> I watched the last car take the bend
> and felt the platform hold my weight
> like a promise I had made myself.
> To stop is to own the hour.
> To stay is to spend it where you stand.

## Run

```sh
python3 main.py
```

Writes the poem to `/output/entry.txt` (205 Unicode code points, deterministic — identical bytes on every run).
